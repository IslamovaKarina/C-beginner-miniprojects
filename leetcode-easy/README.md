The very first problem on LeetCode is called Two Sum.
For those who aren't familiar with memory management in C, this problem might seem complicated but it's actually not that hard!
The brute-force solution has a time complexity of O(n²) and the logic is pretty straightforward.
We can start by solving it without worrying about dynamic memory allocation (`malloc`) and `free`.
