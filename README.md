# C-beginner-miniprojects
I'm learning C and uploading my solutions as I practice basic concepts like variables, loops, conditionals, arrays, and functions. This repository documents my progress as a beginner.

This is a mini-game where you try to guess a number chosen randomly by the computer.
The program uses libraries such as `stdio.h`, `stdlib.h`, and `time.h`.
By working on this project, you can practice using `while` loops, `if` and `else if` statements, and random number generation.
By the way, if you're familiar with binary search, you can guess the number in at most four attempts!
